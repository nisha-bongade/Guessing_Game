<h1>Guess the Number</h1>

<h4>About this game</h4>
<p>Test your brain! Guess the secret number, get hints (higher or lower).</p>

<h4>HOW TO PLAY</h4>
<ul>
  <li>Guess the secret number within the range 1 to 50 that computer generated.</li>
  <li>"TOO HIGH" means the guess number is bigger than secret number</li>
  <li>"TOO LOW" means the guess number is smaller than secret number</li>
</ul>
